# TapArcade

A free browser-game arcade with **2,700+ HTML5 titles** across 19 categories.

**Play:** https://targaryenquiz.xyz

## What it is

TapArcade is a catalog-style arcade site. Games are grouped into 19 categories
(.io, 2-player, 3D, action, adventure, arcade, bejeweled, boys, clicker, cooking,
fighting, girls, hypercasual, multiplayer, puzzles, racing, shooting, soccer,
sports) and load in an embedded player — no download, no account.

## Notes

- This repository tracks site metadata, category structure and the sitemap pipeline.
- Game artwork and gameplay belong to their respective publishers; TapArcade only
  embeds publicly available browser games.
- Sitemap: https://targaryenquiz.xyz/sitemap.xml
